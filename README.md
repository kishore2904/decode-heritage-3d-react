# DecodeHeritage 3D scroll website

React + Vite + Three.js + React Three Fiber. The DNA particles begin scattered and progressively interpolate into a double helix as the visitor scrolls.

## Run locally
Requires Node.js 18+ (20+ recommended).

```bash
npm install
npm run dev
```

Build for deployment:

```bash
npm run build
npm run preview
```

Deploy the generated `dist/` folder to Netlify, Vercel, or another static host.

## Customize
- `src/App.jsx`: section copy, links, DNA geometry and scroll behavior.
- `src/styles.css`: colors, typography, spacing, responsive layout.
- `index.html`: page title and meta description.
